# Cómo activar Cruza RD (paso a paso)

## 1. Espera a que compile
Abajo a la derecha en Unity: si dice **Compiling…**, espera.
La barra roja *"All compiler errors…"* debe **desaparecer**.

## 2. Arranca el juego (elige UNA forma)

### Opción A — más fácil
Menú superior: **Cruza RD → ▶ ABRIR Y JUGAR PROTOTIPO**

### Opción B — manual
1. Project → `Assets/_Project/Scenes/Prototype`
2. Doble clic en `Prototype`
3. Botón **▶ Play** (arriba al centro)

### Opción C — escena vacía
Si estás en **Untitled**, igual puedes pulsar **▶ Play**:
el juego se genera solo (menú CRUZA RD + calles grises).

## 3. Controles
| Input | Acción |
|---|---|
| **JUGAR** (botón en pantalla) | Empieza la partida |
| Swipe / WASD / flechas | Mover |
| Ajustes → D-pad | Controles en pantalla |

## 4. Qué debes ver
- Menú oscuro con **CRUZA RD** / **¡Quítate del Medio!**
- Al jugar: cápsula blanca (tú), carriles, vehículos azules
- HUD: puntaje, metros, papeletas

Si solo ves cielo vacío en Edit Mode: **normal** hasta pulsar Play (o abrir Prototype).
